## 🎯 عن المشروع

**موقع إلكتروني متكامل + لوحة تحكم** لـ **قصر عابدين للمخبوزات والحلويات**.

- 🥐 **35 قسم** مخبوزات وحلويات شرقية وغربية
- 🏬 **15 فرع** في الإسكندرية
- 🛒 سلة تسوق + اختيار الفرع الأقرب
- 📱 **PWA** — يشتغل كتطبيق على الموبايل
- 🎨 هوية بصرية **أسود فخم + ذهبي ملكي**
- 🎛️ لوحة تحكم كاملة لصاحب المحل

---

## ✨ المميزات

### 🏪 للعملاء

- تصفح **35 قسم** بمنتجات متنوعة
- **بيع بالعدد** (خبز، باتيه، كرواسون)
- **بيع بالكيلو** (كوكيز، بقلاوة، حلويات شرقية)
- **أحجام مختلفة** (وسط / كبير)
- **خيارات كمية سريعة** (10/20/30 أو ربع/نصف/كيلو)
- **مربع كمية مخصص** لكتابة العدد
- **السلة + اختيار الفرع**
- إرسال الطلب على **واتساب الفرع مباشرة**

### 🎛️ لصاحب المحل (لوحة التحكم)

- إدارة **35 قسم** (إضافة/تعديل/حذف)
- إدارة **15 فرع** (اسم + عنوان + واتساب)
- تحديد **نوع البيع** (عدد / كيلو)
- **خيارات الكمية** القابلة للتعديل
- إدارة **المنتجات + الصور**
- إدارة **العروض** (صورة + نص)
- **رفع الصور** مباشرة من الموبايل
- حفظ التعديلات على **GitHub** تلقائياً
